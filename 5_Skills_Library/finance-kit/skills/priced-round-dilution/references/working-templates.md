## Financial model checks
Use one currency and state units. Reconcile opening balance plus movements to closing balance. Keep actuals and forecasts distinct. Treat a missing value differently from zero. Show where illustrative assumptions replace absent data. Preserve source documents. Review formulas and calculated results, not only workbook appearance.
